# ABC Academy — Static 3-Page Website

## Pages
- `index.html` — Interest / start page
- `education.html` — Education & Courses
- `services.html` — Fashion & Beauty Services

## Static editing
All visible text, course/service details and image URLs are written directly inside the three HTML files. Open the required page in VS Code and edit the text or the `src="..."` value of an `<img>` tag.

The JavaScript files are used only for visual and interactive behavior such as theme switching, carousels, reveal animations, menu behavior and popup card effects. They do not load website content from a database or external content-management runtime.

## Retained functionality
The glass effect, animations, responsive layout, hero carousel, portfolio carousel, alumni carousel, hover/click popups, dark/light mode, WhatsApp enquiry buttons and enquiry forms are retained.

## Local testing
Open the folder in VS Code with Live Server, or use any simple static web server. No Node.js or database dependency is required.
